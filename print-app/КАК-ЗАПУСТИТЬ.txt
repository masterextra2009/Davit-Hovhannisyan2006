========================================
  ФОТО-СЕВЕР — ПЕЧАТЬ (Этап 1)
  Как запустить на компьютере
========================================

Что это:
Маленькая программа, которая находит все твои принтеры
и печатает на любой из них тестовую страницу.
Это первый шаг — проверить, что всё работает.


-----------------------------------------
САМЫЙ ПРОСТОЙ СПОСОБ (через Claude Code)
-----------------------------------------
У тебя на компьютере установлен Claude Code.
Просто открой эту папку в Claude Code и напиши ему:

   "Запусти эту программу: сначала npm install, потом npm start"

Claude Code сам всё сделает в терминале. Если что-то
не так — он подскажет.


-----------------------------------------
СПОСОБ ВРУЧНУЮ (если хочешь сам)
-----------------------------------------

ШАГ 1. Установи Node.js (если ещё нет)
   - Зайди на https://nodejs.org
   - Скачай кнопку "LTS" и установи (просто "Далее — Далее").

ШАГ 2. Открой эту папку в терминале
   - Открой папку "foto-sever-print"
   - В адресной строке папки напиши слово: cmd
   - Нажми Enter — откроется чёрное окно.

ШАГ 3. Установи детали программы
   - В чёрном окне напиши и нажми Enter:
       npm install
   - Подожди пару минут (скачаются нужные файлы).

ШАГ 4. Запусти программу
   - Напиши и нажми Enter:
       npm start
   - Откроется окно "Фото-Север — Печать".
   - Нажми "Найти принтеры" и попробуй "Печать теста".


-----------------------------------------
КАК СДЕЛАТЬ .EXE (установщик) — позже
-----------------------------------------
Когда убедимся, что всё печатает, соберём установщик.
Для этого в чёрном окне пишется команда:
       npm run dist
Готовый установщик появится в папке "dist".
Но это ЭТАП 4 — сначала проверим печать.


Если что-то не получится — просто пришли мне
скриншот чёрного окна, я подскажу, что делать.
