# nginx-правило для sever-18.ru

Сайт — статичное одностраничное приложение (Vite/React), без `index.php` и без клиентского роутинга по URL: все разделы (личный кабинет, заказы, чат и т.д.) переключаются JS-состоянием на одной странице `/`, отдельных адресов для них не существует. Единственный отдельный путь — `/share-target` (Web Share Target API для PWA).

```nginx
location / {
    # Обычная раздача статики: index.html как индекс,
    # реальные файлы и папки (картинки, /policy/, /privacy/ и т.д.)
    # отдаются как есть. Если совпадения нет — честный 404,
    # а не index.html.
    index index.html;
    try_files $uri $uri/ =404;
}

location = /share-target {
    # Единственный настоящий виртуальный путь на сайте — конечная
    # точка Web Share Target (PWA), сюда браузер шлёт POST при
    # "поделиться файлом" в установленное приложение. Должен
    # открывать index.html, а не 404.
    try_files /index.html =404;
}
```

Обработку `/api/*.php` (загрузка файлов, приём платежей) это правило не затрагивает — она идёт по отдельному `location ~ \.php$`, у которого более высокий приоритет совпадения в nginx.
